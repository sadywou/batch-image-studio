Функциональность приложения
===========================

Пользовательские сценарии
-------------------------

Приложение работает по одному основному сценарию, который повторяет три
состояния из макета: добавление файлов, обработка, результат.

#. **Начало.** Пустая очередь, пунктирная зона перетаскивания, кнопка
   «СТАРТ ОБРАБОТКИ».
#. **Процесс.** Карточки очереди с миниатюрой, размером и статусом,
   предпросмотр выбранного файла, индикатор прогресса, подпись
   «Обработано: N из M файлов (P%)» и кнопка «ОТМЕНА».
#. **Готово.** Все файлы со статусом «Готово», сообщение «Обработка завершена»
   и кнопка «ОБРАБОТАТЬ ЕЩЁ», возвращающая окно в начальное состояние.

Описание элементов интерфейса
-----------------------------

Очередь файлов
~~~~~~~~~~~~~~

============================  =================================================
Элемент                       Назначение
«+ Добавить файлы»            Выбор отдельных изображений через диалог
«Добавить папку»              Выбор папки; в очередь попадают изображения
«Очистить»                    Полная очистка очереди
Пунктирная зона               Приём файлов, перетащенных из файлового менеджера
Карточка файла                Миниатюра, имя, размер, статус, кнопка удаления
Полоса прокрутки              Прокрутка больших списков
«Сравнение до и после»        Исходник и результат выбранного файла
============================  =================================================

Дубликаты и неподдерживаемые файлы отбрасываются автоматически. Пока идёт
обработка, очередь заблокирована: добавление и удаление недоступны.

Настройки пресета
~~~~~~~~~~~~~~~~~

============================  =================================================
Параметр                      Диапазон и назначение
Целевой формат                PNG, JPG, WebP, BMP, TIFF, GIF, ICO, HEIC, AVIF
Ширина и высота               Целые числа больше нуля; пустое поле — не менять эту сторону
«Сохранять пропорции»         Расчёт коэффициента масштаба по меньшей стороне
Качество сжатия               От 1 до 100, ползунок
«Удалить EXIF-метаданные»     Очистка скрытых данных исходника
Водяной знак                  Текст или файл PNG, положение в одной из девяти позиций, размер и цвет
Прозрачность знака            От 0 до 100 процентов
Папка сохранения              Куда записывать готовые файлы
«Сохранить»                   Сохранение настроек под именем в базу
============================  =================================================

Обработка изображений
---------------------

Порядок операций над каждым файлом
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

#. Проверка существования исходного файла.
#. Создание папки назначения.
#. Чтение файла; для анимированных форматов берётся первый кадр.
#. Изменение размера с сохранением пропорций (интерполяция LANCZOS).
#. Наложение водяного знака с прозрачностью.
#. Очистка EXIF-метаданных, если включён соответствующий переключатель.
#. Приведение цветового режима к совместимому с целевым форматом.
#. Сохранение результата с заданным качеством.

Защита исходных данных
~~~~~~~~~~~~~~~~~~~~~~

Результат никогда не перезаписывает исходник. Если имя совпадает с уже
существующим файлом, добавляется суффикс ``_processed``, а при повторном
совпадении — номер: ``_processed_2``, ``_processed_3`` и так далее.

Особенности форматов
~~~~~~~~~~~~~~~~~~~~

============  ==================================================================
Формат        Особенности обработки
PNG           Прозрачность сохраняется без изменений
JPG           Альфа-канал заменяется белым фоном, применяется качество
WebP          Прозрачность сохраняется, применяется качество
BMP           Только режим RGB, качество не применяется
TIFF          Качество не применяется
GIF           Изображение переводится в палитровый режим
ICO           Создаётся один файл с размерами 16×16, 32×32 и 64×64
HEIC, AVIF    Требуются пакеты pillow-heif и pillow-avif-plugin
============  ==================================================================

Журнал обработки
----------------

Каждый запуск записывается в таблицы ``tbl_history_sessions`` и
``tbl_processed_files``. В журнале хранятся имя пресета, время начала и
окончания, общее число файлов, число успешных и неуспешных, длительность,
а также пути исходника и результата, размеры до и после, статус и текст
ошибки.

Внутренний API
--------------

Приложение не предоставляет сетевого API, но имеет чёткий внутренний
интерфейс между модулями. Его достаточно, чтобы использовать обработчик
из другой программы.

.. code-block:: python

   from pathlib import Path
   from app.models import Preset
   from app.processor import ImageProcessor

   preset = Preset(
       name="Для сайта",
       output_format="WebP",
       width=1600,
       height=900,
       quality=85,
       clear_exif=True,
       output_dir="C:/Готово",
   )

   результат = ImageProcessor().process(Path("C:/Фото/снимок.jpg"), preset)
   print(результат)

Пакетная обработка без интерфейса:

.. code-block:: python

   from app.models import Preset, QueueItem
   from app.processor import ImageProcessor
   from app.worker import ProcessingWorker

   files = [QueueItem(Path("C:/Фото/1.jpg")), QueueItem(Path("C:/Фото/2.jpg"))]

   def on_update(index, item):
       print(index, item.status, item.progress)

   worker = ProcessingWorker(files, preset, ImageProcessor(),
                             on_update, lambda duration: print("готово", duration))
   worker.start()
   worker.join()

Отмена обработки:

.. code-block:: python

   worker.cancel()   # оставшиеся файлы получат статус «Отменено»

Ошибки и их обработка
---------------------

============================================  ====================================
Ситуация                                      Реакция приложения
Исходный файл удалён                          Статус «Ошибка», текст в очереди
Файл повреждён                                Статус «Ошибка», очередь идёт дальше
Неверный размер или качество                  Диалог с текстом ошибки
Формат без установленного кодека              Диалог с подсказкой по установке
Результат не удалось сохранить                Файл удаляется, статус «Ошибка»
Отсутствует доступ к рабочей папке            Поиск папки в %LOCALAPPDATA%
============================================  ====================================
