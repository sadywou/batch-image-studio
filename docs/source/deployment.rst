Развёртывание и эксплуатация
=============================

Способы поставки
----------------

=================  =====================================================
Способ             Описание
Исходные файлы     Полный проект, запуск через ``python -m app.main``
Готовый ``.exe``   Один файл 34,3 МБ, Python не требуется
Архив с данными    Папка ``data`` переносится вместе с программой
=================  =====================================================

Требования к рабочему месту
---------------------------

* ОС: Windows 10/11.
* Место на диске: 50 МБ под программу, 100 МБ под результаты обработки.
* Оперативная память: от 2 ГБ.
* Права на запись в папку, где размещён исполняемый файл.
  Если прав нет, программа использует ``%LOCALAPPDATA%\ImageBatchStudio``.

Хранение данных
---------------

============================  ================================================
Объект                        Расположение
База профилей и журнала       ``data/presets.db``
Служебные файлы SQLite        ``data/presets.db-wal``, ``data/presets.db-shm``
Готовые изображения           папка, указанная пользователем при обработке
============================  ================================================

Перенос настроек на другой компьютер выполняется копированием папки
``data``. Полный сброс выполняется удалением папки ``data`` — при
следующем запуске она создаётся заново.

Резервное копирование
---------------------

Перед крупной обработкой достаточно скопировать папку ``data``.
Согласованную копию можно получить средствами SQLite:

.. code-block:: bash

   sqlite3 data/presets.db ".backup data/backup.db"

Схема базы устойчива к обновлениям: при первом обращении
отсутствующие столбцы добавляются автоматически, существующие данные
не изменяются.

Обновление программы
--------------------

1. Закройте программу.
2. Скопируйте новый ``ImageBatchStudio.exe`` рядом со старым.
3. Запустите новую версию — база обновится автоматически.
4. При необходимости верните предыдущий файл: схема базы дополняется
   только новыми столбцами, поэтому старая версия продолжит работать.

Откат версии
------------

Схема базы расширяется только вперёд и не удаляет данные, поэтому откат
до предыдущей версии приложения не требует восстановления базы.
