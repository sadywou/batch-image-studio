Руководство пользователя
========================

Пользователь приложения — специалист, которому нужно подготовить фотографии
к публикации или отправить их в печать. Никаких специальных знаний
не требуется: достаточно уметь работать с файлами и папками.

1. Назначение программы
-----------------------

**1.1. Общая информация**

Image Batch Studio предназначена для массовой обработки изображений:
конвертации, изменения размера, очистки EXIF-метаданных, наложения
текстового водяного знака и сохранения профилей настроек.

**1.2. Функции программы**

* пакетная обработка изображений;
* конвертация в девять форматов;
* изменение размера с сохранением пропорций;
* удаление скрытых EXIF-метаданных;
* наложение текстового водяного знака;
* сохранение и повторное применение профилей настроек;
* журнал выполненных обработок.

2. Условия выполнения программы
-------------------------------

**2.1. Технические требования**

* Операционная система: Windows 10 или 11.
* Свободное место на диске: от 50 МБ для программы и от 100 МБ для результатов.
* Оперативная память: от 2 ГБ (для снимков Full HD рекомендуется 4 ГБ).

Python и дополнительные библиотеки устанавливать **не требуется**:
в готовом файле они уже встроены.

**2.2. Программные требования**

Дополнительные пакеты не нужны. Кодеки форматов HEIC и AVIF уже включены
в готовый файл. При работе с исходниками их нужно установить отдельно.

3. Выполнение программы
-----------------------

**3.1. Загрузка и запуск**

1. Скопируйте ``BatchImageStudio.exe`` в папку, например ``C:\BatchImageStudio``.
2. Дважды щёлкните по файлу.

.. important::

   Не запускайте программу из папки ``C:\Program Files``: у вас нет прав
   на запись в неё. Программа в этом случае сама переносит базу в
   ``%LOCALAPPDATA%\BatchImageStudio``.

**3.2. Управление выполнением**

Добавьте изображения, настройте параметры, запустите обработку и проверьте
результат:

* «+ Добавить файлы» — выбрать несколько изображений;
* «Добавить папку» — добавить все изображения из папки;
* перетащить файлы в пунктирную область;
* «×» на карточке — убрать файл из очереди;
* «Очистить» — убрать все файлы;
* «СТАРТ ОБРАБОТКИ» — начать обработку;
* «ОТМЕНА» — прервать обработку;
* «ОБРАБОТАТЬ ЕЩЁ» — вернуться к началу.

**3.3. Сохранение настроек**

Введите имя в поле профиля и нажмите «Сохранить». В следующий раз
выберите профиль из выпадающего списка — настройки восстановятся.

**3.4. Завершение работы**

Закройте окно программы. Все обработанные файлы уже записаны на диск,
данные профилей сохраняются автоматически.

4. Сообщения оператору
----------------------

**4.1. Тексты сообщений**

Информационные сообщения:

* «Обработка завершена» — все файлы обработаны;
* «Обработка завершена с ошибками» — часть файлов не обработана;
* «Обработка отменена» — обработка была прервана;
* «Профиль сохранён» — настройки записаны в базу.

Предупреждения:

* «Обработка выполняется» — очередь заблокирована до окончания обработки;
* «Очередь пуста» — нечего обрабатывать.

Ошибки:

* «Проверьте настройки» — неверный размер, качество или формат;
* «Не удалось сохранить профиль» — проверьте доступ к папке с базой;
* «Файл не найден» — исходный файл удалён до начала обработки;
* «Файл не является поддерживаемым изображением или повреждён».

**4.2. Действия по сообщениям**

Для информационных сообщений дополнительных действий не требуется.
Для предупреждений нужно дождаться окончания обработки.
Для ошибок проверьте указанные параметры и повторите действие.

**4.3. Возможности повторного запуска**

Если файл не обработался, исправьте причину и запустите обработку
повторно: программа не удаляет уже готовые результаты.

5. Устранение типовых проблем
-----------------------------

.. list-table::
   :header-rows: 1
   :widths: 35 30 35

   * - Проблема
     - Причина
     - Решение
   * - Программа не запускается
     - Блокировка SmartScreen
     - «Подробнее» → «Выполнить в любом случае»
   * - Перетаскивание файлов не работает
     - Не загрузилась библиотека tkdnd
     - Пользуйтесь кнопками добавления
   * - «Требуется дополнительный пакет»
     - Не установлен кодек HEIC или AVIF
     - Обновите сборку либо установите пакет
   * - Готового файла нет в папке
     - Имя совпало с существующим файлом
     - Найдите файл с суффиксом ``_processed``
   * - Профили пропали после перезапуска
     - Нет прав на запись рядом с программой
     - Переместите программу в доступную для записи папку
   * - «Ширина должна быть положительным числом»
     - Введено 0 или отрицательное значение
     - Оставьте поле пустым или введите число больше нуля
