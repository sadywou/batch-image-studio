Image Batch Studio — документация
=================================

**Студия пакетной обработки графики** — настольное приложение для массовой
обработки изображений: конвертация, изменение размера, очистка EXIF-метаданных,
текстовый и графический водяной знак, сохранение профилей настроек и журнал обработки.

Документация описывает приложение на двух уровнях: как им пользоваться и как
его дорабатывать. Раздел :doc:`api` формируется автоматически из docstrings
исходного кода, поэтому всегда соответствует текущей версии программы.

Быстрый старт
--------------

Запуск готового файла::

   dist\BatchImageStudio.exe

Запуск из исходных файлов::

   python -m venv .venv
   .venv\Scripts\activate
   poetry install
   python -m app.main

Связь с исходным кодом
----------------------

Документация и код находятся в одном репозитории. Описание классов
и функций в разделе :doc:`api` генерируется из docstrings модулей
``app/processor.py``, ``app/database.py``, ``app/worker.py`` и ``app/models.py``,
поэтому после изменения кода достаточно повторить сборку::

   sphinx-build -b html docs/source docs/_build/html
