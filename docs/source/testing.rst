Проверка безопасности
---------------------

Проверяются два вида угроз.

**Внедрение SQL.** Типовые строки вида ``'; DROP TABLE tbl_presets; --``
подставляются в имена профилей и справочника форматов. Значение
сохраняется как обычный текст, таблицы остаются целыми.

**Сборка текста запроса.** Модуль ``ast`` разбирает ``app/database.py`` и
требует, чтобы вне метода миграции схемы текст запроса был строковым
литералом. Нарушение этого правила приводит к падению теста.

Дополнительно проверяется, что путь вывода не позволяет выйти за пределы
папки, выбранной пользователем, а исходные файлы никогда не
перезаписываются.

Ручное тестирование
-------------------

Автоматические тесты не покрывают визуальное восприятие и Drag-and-Drop.
Эти сценарии проверялись вручную на Windows 11: добавление файлов кнопками
и перетаскиванием, выбор и предпросмотр, удаление файла, очистка очереди,
сохранение и загрузка профиля, запуск, отмена и возврат по кнопке
«ОБРАБОТАТЬ ЕЩЁ», а также запуск собранного файла из отдельной папки.
