Бэклог продукта
===============

Бэклог — упорядоченный список того, что может быть улучшено в следующих
версиях. Записи приоритизированы: **P1** — заметно влияет на ценность
приложения, **P2** — повышает удобство, **P3** — расширяет возможности.

Текущая версия: 1.0.0. Состояние: все дефекты, найденные на этапах
тестирования и приёмочного прогона, устранены.

Известные ограничения текущей версии
-------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Ограничение
     - Планируемое решение
   * - Анимация GIF
     - Сохраняется только первый кадр. Рассматривается поддержка
       сохранения анимации — IBS-207
   * - ICO
     - Создаётся один файл с тремя размерами, увеличение исходника
       не выполняется — IBS-208
   * - Водяной знак
     - Только текст в четырёх положениях — IBS-102

Технический долг
----------------

* Покрытие ``app/ui.py`` составляет 85 %: непокрыты обработчики наведения
  мыши, анимации кнопок и прокрутки. Стоит расширить тесты событий мыши.
* Обработка выполняется последовательно, в одном потоке — главный резерв
  производительности (IBS-101).
* Тесты интерфейса требуют графического окружения, поэтому в конвейере
  без дисплея их нужно пропускать.
* Замеры производительности сделаны на одной конфигурации; на других
  компьютерах значения будут отличаться.
