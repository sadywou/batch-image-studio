Сообщения приложения
====================

Все сообщения, которые приложение показывает пользователю или
разработчику, собраны в одном месте. Это облегчает поиск нужной формулировки
и проверку того, что интерфейс не сообщает об ошибке техническим языком.

Сообщения пользователю
----------------------

Информационные
~~~~~~~~~~~~~~

============================================  ==================================
Текст                                         Когда выводится
«Обработка завершена»                         Очередь обработана без ошибок
«Обработка завершена с ошибками»              Есть файлы со статусом «Ошибка»
«Обработка отменена»                          Пользователь нажал «ОТМЕНА»
«Профиль сохранён»                            Настройки записаны в базу
============================================  ==================================

Предупреждения
~~~~~~~~~~~~~~

============================================  ========================================
Текст                                         Когда выводится
«Обработка выполняется»                       Попытка изменить очередь в процессе
«Очередь пуста»                               Нажата кнопка запуска без файлов
«Журналирование»                              Результаты готовы, но не записаны в базу
============================================  ========================================

Ошибки
~~~~~~

============================================  ==================================
Текст                                         Когда выводится
============================================  ==================================
«Проверьте настройки»                         Некорректный размер или качество
«Не удалось сохранить профиль»                Ошибка записи в базу
«Файл {имя} не является поддерживаемым
изображением или повреждён»                   Битый файл или неверное расширение
«Не удалось открыть файл {имя}»               Файл недоступен для чтения
«Не удалось сохранить файл {имя}»             Ошибка записи результата
«Формат {формат} требует дополнительный
пакет: pip install {пакет}»                    Нет кодека HEIC или AVIF
«Не удалось подготовить рабочую папку»        Нет прав на запись ни в одну папку
============================================  ==================================

Статусы элементов очереди
-------------------------

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Статус
     - Значение
   * - «В очереди»
     - Файл добавлен, но ещё не обработан
   * - «В обработке»
     - Файл обрабатывается в текущий момент
   * - «Готово»
     - Результат создан
   * - «Ошибка»
     - Обработка не удалась, в карточке указан текст ошибки
   * - «Отменено»
     - Обработка прервана пользователем

Сообщения для разработчика
--------------------------

Исключения :class:`app.processor.ImageProcessor`:

=========================  ==========================================================
Исключение                 Причина
=========================  ==========================================================
``FileNotFoundError``      Исходный файл не найден
``ValueError``             Неверный формат, размер, качество или прозрачность
``RuntimeError``           Файл повреждён, не является изображением, либо
                           результат не удалось сохранить
=========================  ==========================================================

Исключения :class:`app.database.DatabaseManager`:

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Исключение
     - Причина
   * - ``ValueError``
     - Неизвестный формат, профиль не найден, пустое имя, недопустимое
       имя объекта миграции
   * - ``sqlite3.IntegrityError``
     - Нарушено ограничение UNIQUE или CHECK
   * - ``RuntimeError``
     - Рабочая папка недоступна для записи

Сообщения сборки и проверок
---------------------------

* ``flake8 app tests`` — «ни одного замечания» означает, что стиль кода
  и потенциальные ошибки в порядке.
* ``pytest -q`` — ожидается строка ``143 passed``; любое другое число
  означает, что часть тестов не выполнена.
* ``tools/check_exe.py`` — «Итог: исполняемый файл запускается» подтверждает,
  что программа работоспособна без Python.
