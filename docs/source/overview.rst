Обзор приложения
================

Назначение
----------

Image Batch Studio предназначена для массовой подготовки изображений к публикации:
администраторам сайтов, блогерам, фотографам, SMM-специалистам и
контент-менеджерам. Пользователь добавляет в очередь фотографии, задаёт общие
параметры обработки и получает готовые файлы в выбранной папке.

Проблема, которую решает приложение
-----------------------------------

Поштучная обработка графики занимает много времени: для каждого снимка нужно
отдельно менять размер, конвертировать формат и накладывать копирайт. Кроме
того, при публикации фотографий в сети есть риск утечки приватных
EXIF-метаданных — геолокации и сведений о модели камеры.

Основные возможности
--------------------

* пакетная обработка изображений, добавление файлов, папок и перетаскивание;
* конвертация в девять форматов: PNG, JPG, WebP, BMP, TIFF, GIF, ICO, HEIC, AVIF;
* изменение размера с сохранением пропорций по алгоритму LANCZOS;
* регулировка качества сжатия от 1 до 100 процентов;
* очистка скрытых EXIF-метаданных одним переключателем;
* водяной знак: текстовый или графический (PNG) с выбором файла, девять позиций размещения, настройка прозрачности, размера и цвета;
* сохранение и загрузка профилей настроек;
* журнал сессий обработки в локальной базе SQLite;
* фоновая обработка с индикатором прогресса и возможностью отмены;
* сравнение результата с оригиналом до и после обработки.

Принципы работы
---------------

Приложение построено по трёхуровневой архитектуре. Графический интерфейс
не содержит вычислительной логики: он только собирает параметры в объект
``Preset`` и отображает состояние очереди. Обработку выполняет класс
``ImageProcessor`` — он не зависит от интерфейса и может использоваться
самостоятельно. Все данные хранятся в локальной базе SQLite, работа с которой
вынесена в класс ``DatabaseManager``.

Такой подход даёт три преимущества:

#. Бизнес-логику можно тестировать без запуска окна.
#. Изменение внешнего вида не затрагивает обработку изображений.
#. Приложение работает полностью локально и не обращается в Интернет.

Границы применимости
--------------------

Программа рассчитана на работу одного пользователя на одном компьютере.
Она не предназначена для обработки в многопользовательском режиме,
для публикации в сеть и для работы с видео.

Анимированные изображения обрабатываются как первый кадр: исходная анимация
не сохраняется. Для формата ICO создаётся один файл с тремя изображениями
16×16, 32×32 и 64×64.

Ограничения и известные проблемы перечислены в разделе
:doc:`developer_manual`.
