# Трекер задач и дефектов

Файл повторяет формат «Issues» на GitHub и служит единым списком работ
по сопровождению приложения после релиза 1.0.0.

Система контроля версий в среде разработки недоступна (Git не установлен),
поэтому история изменений ведётся вручную: см. [CHANGELOG.md](../CHANGELOG.md).
При появлении доступа к Git этот файл переносится в раздел Issues
репозитория без изменения структуры.

## Шкала приоритетов

| Приоритет | Значение |
|---|---|
| **P0 — критический** | Приложение не запускается или теряются данные пользователя. Исправляется немедленно. |
| **P1 — высокий** | Основная функция работает неверно или недоступна. Исправляется в текущей версии. |
| **P2 — средний** | Есть обходной путь, функция неудобна. Планируется в следующей версии. |
| **P3 — низкий** | Косметика и улучшения. Переносится в бэклог. |

## Порядок работы с трекером

1. Дефект воспроизводится и заводится запись с приоритетом.
2. На приоритет P0 или P1 создаётся ветка от `main` и отдельный тест,
   который падает до исправления.
3. Исправление проверяется прогоном `flake8 app tests` и `pytest -q`.
4. Запись дополняется номером версии, в которой исправление вышло.
5. Завершённые записи переносятся в `CHANGELOG.md`.
