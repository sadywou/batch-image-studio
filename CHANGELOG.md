# Журнал изменений

Все значимые изменения приложения фиксируются здесь. Формат соответствует
«Keep a Changelog», версии — по семантической схеме.

## [1.0.0] — 13 октября 2026

Первый стабильный релиз: приложение готово к передаче пользователю.

### Добавлено

- Главное окно Tkinter с тремя состояниями макета: «Начало», «Процесс», «Готово».
- Пакетная обработка изображений с добавлением файлов, папок и перетаскиванием.
- Конвертация в девять форматов: PNG, JPG, WebP, BMP, TIFF, GIF, ICO, HEIC, AVIF.
- Изменение размера с сохранением пропорций по алгоритму LANCZOS.
- Очистка EXIF-метаданных по переключателю.
- Текстовый водяной знак в четырёх положениях с настройкой прозрачности.
- Профили настроек в локальной базе SQLite.
- Журнал сессий и файлов обработки.
- Фоновая обработка в отдельном потоке с отменой.
- 143 автоматических теста, покрытие кода приложения 88 %.
- Сборка в один исполняемый файл `ImageBatchStudio.exe` (34,3 МБ).
- Документация Sphinx в форматах HTML и PDF.
- Руководство пользователя и руководство разработчика.
- Бэклог продукта и трекер дефектов.

### Исправлено

- Флажок «Очистить EXIF» влиял на результат независимо от положения.
- Повреждённый файл больше не приводит к необработанному исключению.
- Собранный `.exe` запускается: добавлена отдельная точка входа `run_app.py`.
- Рабочая база в `.exe` хранится рядом с программой, а не во временной папке.
- Имена объектов миграции схемы проверяются по белому списку.
- Блок «После обработки» отображает результат по мере готовности файла.
- Приложение не падает, если библиотека tkdnd не загрузилась.
- Кэш миниатюр очищается при создании окна.

### Известные ограничения

- Анимированные изображения обрабатываются как первый кадр.
- Для ICO создаётся один файл с размерами 16×16, 32×32 и 64×64.
- Водяной знак поддерживается только в текстовом виде.
- Время обработки снимка Full HD — около 0,21 с при целевом значении 0,1 с.
