# Журнал изменений

Все значимые изменения приложения фиксируются здесь. Формат соответствует
«Keep a Changelog», версии — по семантической схеме.

## [1.1.0] — 13 октября 2026

Приведение программы в полное соответствие техническому заданию
по ГОСТ 34.602-2020. Выявлено и устранено 11 расхождений.

### Добавлено

- Графический водяной знак: выбор внешнего логотипа PNG с альфа-каналом
  кнопкой рядом с полем ввода.
- Настройка размера водяного знака от 1 до 20 % и выбор цвета текста.
- Собственный выпадающий список RoundedCombo: скруглённое поле со стрелкой,
  всплывающее меню тёмной темы с подсветкой строки и галочкой выбора
  вместо стандартного списка ttk.
- Образец выбора цвета ColorSwatch вместо плоской кнопки с рамкой.
- Ползунок с тонкой дорожкой 6 пикселей, круглым бегунком и увеличением
  при наведении.
- Скруглённая рамка панели журнала выполнения.
- 20 автоматических проверок оформления в 	ests/test_ui_widgets.py.
- Текстовый журнал выполнения с цветовой разметкой сообщений, закреплённый
  внизу карточки настроек и всегда видимый.
- Строка меню «Помощь» с пунктами «О программе» и «Руководство пользователя».
- Девять позиций водяного знака по сетке 3×3, включая центр изображения.
- Управление зависимостями через Poetry: `pyproject.toml` и `poetry.lock`.
- Инструкция по установке Poetry в файле `INSTALL_POETRY.md`.
- Скрипты проверки соответствия: `check_spec_metrics.py` (п. 4.1.3),
  `check_acceptance.py` (п. 6.1), `fix_spec_document.py`,
  `make_spec_compliance.py`, `build_pdf.py`.
- Набор `tests/test_ui_layout.py` — 23 проверки вёрстки карточки настроек.
- Фикстура `window` вынесена в `tests/conftest.py` для всех наборов
  тестов интерфейса.

### Изменено

- Размер задаётся привычными полями ширины и высоты в пикселях.
  Режим определяется по заполненным полям: оба пусты — размер не меняется,
  заполнено одно — масштабирование по этой стороне, заполнены оба —
  вписывание в габаритный прямоугольник. В поле ширины можно указать
  процент вида `50%`.
- Схема базы приведена к п. 4.3.2: имена таблиц и столбцов, а также статус
  завершения SUCCESS или ERROR вместо русских значений.
- Автоматическая миграция баз предыдущих версий: переименование столбцов,
  добавление новых, перевод статусов и прозрачности. Данные сохраняются.
- Ведомость расхождений технического задания и реализации с обоснованием
  четырёх сознательно принятых отклонений.
- Исправленный экземпляр технического задания: заполнена группа, уточнены
  сроки разработки, в перечисление `resize_mode` добавлен режим FIT.
- Документация: девять позиций знака, графический знак, переход на Poetry.

### Исправлено

- Профиль в режиме «Без изменения» восстанавливался со значением 1920
  вместо пустого: пустая строка ошибочно считалась отсутствующей.
- Позиция «Центр» для водяного знака вычислялась как правый нижний угол.
- Блок выбора логотипа появлялся под формой, а не на месте текстового
  поля, поэтому кнопка выбора файла была не видна.
- Полоса прокрутки карточки настроек занимала место у списка полей:
  прокручиваемая область теряла около 260 пикселей высоты.
- Панель настроек показывала неверную подсказку о режиме масштабирования.

## [1.0.0] — 13 октября 2026

Первый стабильный релиз: приложение готово к передаче пользователю.

### Добавлено

- Главное окно Tkinter с тремя состояниями макета: «Начало», «Процесс», «Готово».
- Пакетная обработка изображений с добавлением файлов, папок и перетаскиванием.
- Конвертация в девять форматов: PNG, JPG, WebP, BMP, TIFF, GIF, ICO, HEIC, AVIF.
- Изменение размера с сохранением пропорций по алгоритму LANCZOS.
- Очистка EXIF-метаданных по переключателю.
- Текстовый водяной знак в девяти положениях с настройкой прозрачности,
  размера и цвета, а также графический знак из файла PNG.
- Профили настроек в локальной базе SQLite.
- Журнал сессий и файлов обработки.
- Фоновая обработка в отдельном потоке с отменой.
- 143 автоматических теста, покрытие кода приложения 88 %.
- Сборка в один исполняемый файл `BatchImageStudio.exe` (34,3 МБ).
- Документация Sphinx в форматах HTML и PDF.
- Руководство пользователя и руководство разработчика.
- Бэклог продукта и трекер дефектов.

### Исправлено

- Флажок «Очистить EXIF» влиял на результат независимо от положения.
- Повреждённый файл больше не приводит к необработанному исключению.
- Собранный `.exe` запускается: добавлена отдельная точка входа `run_app.py`.
- Рабочая база в `.exe` хранится рядом с программой, а не во временной папке.
- Имена объектов миграции схемы проверяются по белому списку.
- Блок «После обработки» отображает результат по мере готовности файла.
- Приложение не падает, если библиотека tkdnd не загрузилась.
- Кэш миниатюр очищается при создании окна.

### Известные ограничения

- Анимированные изображения обрабатываются как первый кадр.
- Для ICO создаётся один файл с размерами 16×16, 32×32 и 64×64.
- Водяной знак поддерживается только в текстовом виде.
- Время обработки снимка Full HD — около 0,21 с при целевом значении 0,1 с.
