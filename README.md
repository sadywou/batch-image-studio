# Студия пакетной обработки графики (Image Batch Studio)

Учебное desktop-приложение на Python 3.10+, Tkinter, SQLite и Pillow.
Поддерживает добавление файлов и папок, очередь, фоновую обработку, конвертацию
в 9 форматов, изменение размера с сохранением пропорций, очистку EXIF-метаданных,
текстовый и графический водяной знак, боковую панель профилей настроек,
выгрузку отчёта в CSV и журналирование результатов в SQLite.
Оформление выполнено в единой тёмной теме Deep Navy.

Инструкция для пользователя и раздел «Устранение возможных проблем» —
в файле [USER_GUIDE.md](USER_GUIDE.md).

## Быстрый старт

### Готовый исполняемый файл

```bat
dist\BatchImageStudio.exe
```

Python и зависимости установлять не требуется.

### Запуск из исходников

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m app.main
```

Либо `run_windows.bat` (Windows) и `run_linux.sh` (Linux/macOS).

Tkinter должен быть установлен в составе Python (в некоторых Linux-дистрибутивах
нужен отдельный пакет `python3-tk`). Для перетаскивания файлов используется
`tkinterdnd2`; если библиотека недоступна, добавление через диалог файлов
остаётся доступным, а программа выводит понятное сообщение.

## Сборка исполняемого файла

```bat
build_windows.bat
```

Скрипт последовательно выполняет пять шагов: создаёт виртуальное окружение,
устанавливает зависимости, прогоняет `flake8` и `pytest`, создаёт иконку
и собирает один файл `dist\BatchImageStudio.exe` (~33 МБ).

Для Linux/macOS — `sh build_linux.sh` (собирается файл `dist/ImageBatchStudio`).

Спецификация сборки — `ImageBatchStudio.spec`. Точка входа сборки — `run_app.py`:
модуль `app/main.py` использует относительные импорты и не может запускаться
как самостоятельный скрипт.

Проверка готового файла:

```bat
.venv\Scripts\python.exe tools\check_exe.py
```

## Проверки качества

```bat
.venv\Scripts\python.exe -m flake8 app tests
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m pytest --cov=app --cov=tests --cov-report=html
```

Отчёт по покрытия сохраняется в `htmlcov/index.html` и `coverage.xml`.

Дополнительные инструменты дня 13-14:

```bat
python tools\perf_check.py       :: измерение времени отклика и памяти
python tools\profile_stages.py   :: профилирование этапов обработки
python tools\make_icon.py        :: генерация иконки приложения
python tools\check_exe.py        :: проверка готового .exe
```

## Состояния интерфейса

Окно разделено на три карточки: очередь файлов, боковая панель профилей
и форма настроек. Окно повторяет три макета визуального проекта:

1. **Начало** — пустая очередь, пунктирная зона Drag-and-Drop, кнопка «СТАРТ ОБРАБОТКИ».
2. **Процесс** — карточки очереди с миниатюрой, размером, статусом и бейджем
   экономии, предпросмотр выбранного изображения, индикатор прогресса, подпись
   «Обработано: N из M файлов (P%)» и кнопка «ОТМЕНА».
3. **Готово** — у всех файлов статус «Готово», сообщение «Обработка завершена»
   и кнопка «ОБРАБОТАТЬ ЕЩЁ», возвращающая приложение в начальное состояние.

Служебные подписи макета («1. Начало — добавление файлов», «Batch Image Processor»)
в рабочее окно не выводятся: они относятся к оформлению прототипа.

## Элементы оформления

| Элемент | Где применяется |
|---|---|
| Значок приложения | заголовок окна, файл `BatchImageStudio.exe`, ярлыки |
| Бейдж экономии | зелёный «−N % размера» у обработанного файла, красный при росте |
| Пульсирующая рамка | карточка под курсором во время перетаскивания файлов |
| Всплывающие подсказки | кнопки очереди, профилей, запуска и выгрузки отчёта |
| Разделители блоков | тонкие линии между группами полей формы |

Значок создаётся скриптом `tools/make_icon.py`: он рисует знак и сохраняет
файл `build_assets/app.ico` сразу в семи размерах (16…256 пикселей) и копию
`app.png` для заголовка окна. При сборке оба файла кладутся рядом с `.exe`.

## Профили настроек

Профили вынесены в отдельную боковую панель между очередью и формой.
Каждый профиль показан карточкой с названием и кратким составом
(формат, размер, качество, наличие водяного знака), поэтому применять
настройки можно одним щелчком, не открывая выпадающий список.

* поле «ИМЯ ПРОФИЛЯ» — имя нового или выбранного профиля;
* «Сохранить» — создать профиль или обновить существующий (`Enter` в поле);
* «Удалить» — удалить профиль после подтверждения;
* крестик на карточке — удалить профиль напрямую.

## Отчёт об обработке

Кнопка «Экспорт отчёта в CSV» (и пункт меню «Файл») выгружает журнал
сессий и обработанных файлов в таблицу, которая открывается в Excel и
LibreOffice Calc без подготовки. Разделитель — точка с запятой, как принято
в русской версии Excel; кодировка UTF-8 с меткой порядка байтов сохраняет
кириллицу. Экономия размера считается только для успешно обработанных
файлов, чтобы в отчёте не появлялось ложное сокращение.

Тот же отчёт можно получить из командной строки:

```bat
.venv\Scripts\python.exe -m app.reporting отчёт.csv
```

## Поддерживаемые форматы

PNG, JPG/JPEG, WebP, BMP, TIFF, GIF и ICO поддерживаются Pillow.
Для HEIC установите `pillow-heif`, для AVIF — `pillow-avif-plugin`.
В готовом `.exe` эти кодеки уже встроены.

Анимированные изображения обрабатываются как первый кадр; исходная анимация
не сохраняется. Для ICO создаётся один файл с тремя изображениями:
16×16, 32×32 и 64×64, исходник центрируется на прозрачном полотне.

## Где хранятся данные

Рабочая папка определяется автоматически:

* при запуске из исходников — `data/` рядом с проектом;
* в собранном `.exe` — папка `data/` рядом с исполняемым файлом;
* если рядом с `.exe` нет прав на запись — `%LOCALAPPDATA%\ImageBatchStudio`.

## Известные ограничения

- Текстовый водяной знак поддерживает четыре угла; шрифт Arial используется
  при наличии, иначе — стандартный шрифт Pillow.
- При совпадении имени выходного файла создаётся имя с суффиксом `_processed`,
  чтобы не перезаписывать существующий файл.
- Кодирование WebP и AVIF занимает около 82 % времени обработки одного снимка:
  по замерам один файл Full HD обрабатывается примерно за 0,21 с.
- Скорость и потребление памяти зависят от размеров исходных изображений
  и оборудования.
