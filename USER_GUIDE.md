# Инструкция по запуску и настройке

Документ предназначен для конечного пользователя. Он описывает два способа
запуска, основные настройки и порядок действий при типовых ошибках.

---

## 1. Способы запуска

### 1.1. Готовый исполняемый файл (без установки Python)

1. Скопируйте файл `ImageBatchStudio.exe` в любую папку, например `C:\ImageBatchStudio`.
2. Дважды щёлкните по файлу.
3. Никаких дополнительных программ и библиотек устанавливать не нужно:
   Python, Pillow и SQLite уже встроены в файл.

При первом запуске рядом с `.exe` автоматически создаётся папка `data`
с базой настроек `presets.db`.

> **Важно:** не запускайте программу из папки `C:\Program Files` —
> у пользователя нет прав на запись туда. Программа в этом случае
> автоматически переносит базу в `%LOCALAPPDATA%\ImageBatchStudio`.

### 1.2. Запуск из исходных файлов (для разработки)

Требуется Python 3.10 или новее.

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m app.main
```

Для Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python3 -m app.main
```

Либо готовые скрипты: `run_windows.bat` (Windows) и `run_linux.sh` (Linux/macOS).

## 2. Как пользоваться программой

1. **Добавьте файлы.** Кнопки «+ Добавить файлы», «Добавить папку»
   или перетащите файлы в пунктирную область окна.
2. **Настройте обработку** в правой карточке:
   * целевой формат (PNG, JPG, WebP, BMP, TIFF, GIF, ICO, HEIC, AVIF);
   * ширина и высота в пикселях;
   * «Сохранять пропорции» — чтобы картинка не растянулась;
   * качество сжатия от 1 до 100 %;
   * «Очистить EXIF» — удалить скрытые метаданные (геолокация, модель камеры);
   * текстовый водяной знак и его положение;
   * папка для готовых файлов.
3. **Сохраните пресет** (кнопка «Сохранить»), чтобы в следующий раз
   не настраивать параметры заново.
4. **Нажмите «СТАРТ ОБРАБОТКИ».** Внизу появится индикатор прогресса
   и подпись «Обработано: N из M файлов (P%)».
5. **Дождитесь состояния «Готово».** Успешные файлы отмечены статусом
   «Готово», неудачные — «Ошибка» с указанием причины.
6. **«ОБРАБОТАТЬ ЕЩЁ»** очищает очередь и возвращает окно в начальное состояние.

Если результат уже существует, программа не перезаписывает его, а создаёт
файл с суффиксом `_processed` или `_processed_2`, `_processed_3` и так далее.

### Настройка, которую может потребоваться изменить

| Что | Где | Примечание |
|---|---|---|
| Папка сохранения результата | поле «Папка для готовых файлов» в окне | можно указать сетевой диск |
| Место хранения базы настроек | папка `data` рядом с `.exe` | копируется вместе с программой |
| Кодеки HEIC и AVIF | устанавливаются в `.venv` | см. раздел 4 |

Приложение работает полностью локально и не обращается в Интернет,
поэтому прокси, порты и адреса серверов настраивать не требуется.

## 3. Где хранятся данные

| Объект | Путь |
|---|---|
| База профилей и журнала | `data\presets.db` |
| Резервные файлы SQLite | `data\presets.db-wal`, `data\presets.db-shm` |
| Готовые изображения | та папка, которую вы указали при обработке |

Чтобы перенести настройки на другой компьютер, достаточно скопировать
папку `data` вместе с программой. Чтобы начать с нуля, удалите папку `data` —
при следующем запуске она будет создана заново.

---

## 4. Установка кодеков HEIC и AVIF

Форматы PNG, JPG, WebP, BMP, TIFF, GIF и ICO поддерживаются «из коробки».
Для HEIC и AVIF нужны дополнительные пакеты Pillow:

```bat
.venv\Scripts\python.exe -m pip install pillow-heif pillow-avif-plugin
```

В готовом `.exe` эти кодеки уже встроены. Если вы работаете с исходниками,
установите их в том же виртуальном окружении, из которого запускается программа.

## 5. Устранение возможных проблем (Troubleshooting)

### 5.1. Программа не запускается, двойной щелчок ничего не делает

**Причина:** Windows SmartScreen блокирует неподписанный файл.
**Решение:** нажмите «Подробнее» → «Выполнить в любом случае».
Либо запустите файл из командной строки, чтобы увидеть сообщение об ошибке:

```bat
cd /d C:\ImageBatchStudio
ImageBatchStudio.exe
```

### 5.2. Ошибка `Unable to load tkdnd library` или пропадает перетаскивание файлов

**Причина:** не удалось загрузить библиотеку `tkinterdnd2` (тянется за собой
двоичные файлы tkdnd). Возникает на нестандартных сборках Windows
и после переноса `.exe` на компьютер с другой архитектурой.
**Решение:** программа продолжает работать. Используйте кнопки
«Добавить файлы» и «Добавить папку» — перетаскивание необязательно.

### 5.3. Файлы перетаскиваются в окно, но ничего не происходит

**Причина:** окно запущено не из того окружения, где установлена `tkinterdnd2`,
либо запущена старая версия программы.
**Решение:** проверьте пункт 5.2, затем перезапустите программу.

### 5.4. Ошибка «Файл X не является поддерживаемым изображением или повреждён»

**Причина:** файл не является изображением или повреждён (например, был
оборван при копировании).
**Решение:** проверьте файл в стандартном просмотрщике Windows. Остальные
файлы очереди продолжат обрабатываться — программа не прерывает пакет
из-за одного негодного файла.

### 5.5. Ошибка «Формат HEIC/AVIF требует дополнительный пакет»

**Причина:** не установлен кодек для этих форматов.
**Решение:** выполните пункт 4. В готовом `.exe` кодек уже встроен —
это сообщение означает, что запущена устаревшая сборка.

### 5.6. Ошибка «Значение «ширина» должно быть положительным целым числом»

**Причина:** в поле ширины или высоты введён ноль, отрицательное число
или текст.
**Решение:** оставьте поле пустым, если размер не нужно менять, либо
введите целое число больше нуля (например, `1920`).

### 5.7. Кнопка «СТАРТ ОБРАБОТКИ» не реагирует

**Причина:** очередь пуста.
**Решение:** добавьте хотя бы один файл. Если файлы уже добавлены,
проверьте, что обработка не запущена дважды: во время работы доступна
только кнопка «ОТМЕНА».

### 5.8. Программа не закрывается, файл `ImageBatchStudio.exe` не удаляется

**Причина:** окно ещё открыто в фоне.
**Решение:** закройте окно программы обычным способом. Если окно потерялось,
снимите процесс через Диспетчер задач (`Ctrl+Shift+Esc` → «ImageBatchStudio.exe»
→ «Снять задачу»).

### 5.9. База не сохраняется, профили пропадают после перезапуска

**Причина:** папка с программой недоступна для записи (например,
`C:\Program Files`), и программа не смогла создать `data`.
**Решение:** скопируйте `.exe` в папку, куда у вас есть права записи
(например, `C:\ImageBatchStudio`). Смотрите также пункт 5.10.

### 5.10. Сообщение «Не удалось подготовить рабочую папку»

**Причина:** ни одна из доступных папок не принимает запись.
**Решение:** проверьте права на запись. Дополнительно программа ищет
базу в `%LOCALAPPDATA%\ImageBatchStudio`. Если файлы `.exe` и папка
`data` скопированы в OneDrive, временно переместите программу
на локальный диск.

### 5.11. Готовый файл не появился в папке назначения

**Причина:** имя файла совпало с уже существующим — программа создала
`имя_processed.png` вместо перезаписи.
**Решение:** откройте папку назначения и найдите файл с суффиксом
`_processed`. Либо выберите другую папку для результата.

### 5.12. Обработка идёт слишком долго

**Причина:** WebP и AVIF кодируются медленнее PNG и JPEG, а изменение
размера Full HD выполняется по алгоритму LANCZOS.
**Решение:** для массовой обработки выберите PNG или JPEG
(качество 80–85). По результатам замеров (день 13) один снимок Full HD
обрабатывается примерно за 0,21 с, из которых около 0,18 с приходится
на кодирование WebP.

## 6. Проверка целостности установки

Если нужно убедиться, что программа в порядке, запустите из каталога проекта:

```bat
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m flake8 app tests
```

Ожидаемый результат: **142 теста пройдены**, ошибок и предупреждений нет.
